# AI 绘画小程序设计文档

## 1. 项目概述

**项目名称**：AI 绘画小程序
**项目类型**：抖音小程序
**核心功能**：文生图、图生图
**目标用户**：抖音年轻用户，追求个性化头像和趣味图片

## 2. 功能规划

### 2.1 核心功能

| 功能 | 描述 | 收费模式 |
|------|------|----------|
| 文生图（SD） | 文字描述生成图片 | 免费用户看广告，付费会员无限用 |
| 文生图（MJ） | Midjourney 高质量生成 | 仅付费会员可用 |
| 图生图（SD） | 参考图生成新风格图片 | 免费用户看广告，付费会员无限用 |

### 2.2 变现模式

- **流量主模式**：免费用户每次生成需观看广告
- **付费解锁模式**：会员订阅制（按月/按年），去除广告限制

### 2.3 会员权益

- 无广告打扰
- 每月固定生成额度（如 500 张）
- Midjourney 高质量生成权限
- AI 头像（后续扩展）
- AI 表情包（后续扩展）

## 3. 技术架构

### 3.1 前端

- **平台**：抖音小程序
- **框架**：原生开发 或 Taro（跨端）
- **风格**：可爱活泼，明亮配色，圆角风格

### 3.2 后端

- **架构**：云函数 + 云开发数据库
- **框架**：Python（云函数）
- **数据库**：云开发数据库（JSON 文档存储）

### 3.3 AI 对接

| AI 引擎 | 用途 | 接入方式 |
|---------|------|----------|
| Stable Diffusion | 免费/广告档生成 | 第三方 API 服务商 |
| Midjourney | 付费高端生成 | 第三方 API 服务商 |

### 3.4 第三方 API 推荐

- **SD API**：SoulGen、Cartina、BaseImg
- **MJ API**：Midjourney Proxy、SWIBI

## 4. 用户体系

### 4.1 登录方式

- 抖音一键授权登录
- 获取用户唯一标识和基础信息

### 4.2 用户数据

- 用户身份标识
- 会员状态（普通/会员）
- 会员到期时间
- 剩余生成次数
- 生成历史记录（可选存储）

## 5. 数据流设计

```
用户发起生成请求
       ↓
云函数接收请求
       ↓
验证用户权限（广告/会员）
       ↓
调用第三方 AI API（SD/MJ）
       ↓
返回图片 URL
       ↓
小程序展示结果
```

## 6. 页面结构

| 页面 | 功能 |
|------|------|
| 首页 | 功能入口（文生图/图生图） |
| 文生图页 | 文字输入 → 参数选择 → 生成 |
| 图生图页 | 上传参考图 → 参数选择 → 生成 |
| 我的页面 | 会员状态、生成记录、设置 |

## 7. 付费流程

```
用户点击「生成」
       ↓
判断：会员且有额度 → 直接生成
       ↓
非会员 → 弹窗提示「看广告免费生成」
       ↓
用户观看广告 → 获得一次生成机会
       ↓
调用 AI API 生成图片
```

## 8. UI 风格规范

- **整体风格**：可爱活泼，适合年轻人
- **配色**：明亮色调（如粉色、蓝色、黄色）
- **圆角**：大圆角卡片和按钮（16-24rpx）
- **图标**：圆润风格的线性图标
- **字体**：清晰易读，适合移动端

## 9. 技术栈总结

| 层级 | 技术选型 |
|------|----------|
| 前端 | 抖音小程序（原生/Taro） |
| 后端 | 云函数（Python） |
| 数据库 | 云开发数据库 |
| AI | Stable Diffusion API + Midjourney API |
| 登录 | 抖音 OAuth |

### 后续迭代
